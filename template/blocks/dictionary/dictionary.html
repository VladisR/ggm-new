200 OK Status
Код ответа HTTP 200 (OK) — это код ответа, который указывает на успешную обработку запроса клиента сервером. Данный код подтверждает, что запрашиваемый ресурс найден, ошибок нет, и данные успешно переданы пользователю.
3
301 Redirect

301-й редирект (Permanent Redirect) сообщает браузерам и поисковым системам, что запрашиваемая страница была навсегда перемещена на новый URL.

С помощью 301-го редиректа производят «переезды» как отдельных страниц, так и целых сайтов. Он сигнализирует поисковой системе о постоянном изменении адреса, помогая сохранить трафик и передать ссылочный вес на новую страницу.

302 Redirect

302-й редирект указывает на то, что веб-страница или ресурс были перемещены в другое место временно, а не навсегда. В отличие от 301-го редиректа, данный код ответа говорит поисковым системам, что оригинальный URL в какой-то момент снова станет актуальным.

304 Not Modified
Код ответа 304 (Not Modified) сообщает, что запрашиваемый ресурс не изменялся с момента последнего скачивания, поэтому серверу не нужно передавать его заново. Это позволяет браузеру использовать сохраненную в кэше копию страницы, что экономит ресурсы и ускоряет загрузку.
4
404 Error
Ошибка 404 (Not Found) — это HTTP-код состояния, означающий, что сервер не может найти ресурс по запрошенному URL. Это происходит, если страница была удалена, перемещена без настройки переадресации, или если ссылка на нее ведет в никуда.
410 Gone
Код ответа 410 (Gone) указывает на то, что запрошенный ресурс больше недоступен на сервере, и это состояние является постоянным. Этот код выступает более «строгим» сигналом для поисковых систем, чем 404, подтверждая, что страницу следует удалить из индекса, так как она исчезла окончательно.
503 Service Unavailable
Код ответа 503 (Service Unavailable) — это HTTP-код состояния, означающий, что сервер временно не может обработать запрос из-за перегрузки или проведения технических работ.
5
A/B-тестирование

A/B-тестирование (сплит-тестирование) — это метод маркетингового исследования, при котором сравниваются две версии веб-страницы, приложения или оффера (A и B) для определения той, которая показывает лучшую конверсию или вовлеченность пользователей.

Этот инструмент регулярно используется для оптимизации посадочных страниц (лендингов), кнопок призыва к действию и регистрационных форм, чтобы максимизировать показатели конверсий.

AhrefsBot
AhrefsBot — это поисковый робот (краулер) аналитического SEO-сервиса Ahrefs, который непрерывно сканирует интернет для сбора данных об обратных ссылках и метриках сайтов.
Alternate-теги
Alternate-теги — это HTML-атрибуты (rel="alternate"), указывающие поисковым системам на альтернативные версии страницы: мобильную, для другого языка или региона. Чаще всего используются в связке с hreflang для мультиязычных и мультирегиональных проектов, а также для указания AMP-версий страниц.
AMP / Ускоренные мобильные страницы
AMP (Accelerated Mobile Pages) — это технология создания максимально легковесных веб-страниц, предназначенных для мгновенной загрузки на мобильных устройствах. Использование AMP помогает улучшить пользовательский опыт и может дать преимущество в мобильной выдаче поисковых систем.
API

API (Application Programming Interface) — это набор протоколов и инструментов, позволяющий различным программным системам обмениваться данными и взаимодействовать друг с другом.

В SEO API часто используется для массовой выгрузки аналитики из сервисов вроде Google Search Console, автоматического обновления контента на сайте и интеграции данных из сторонних источников.
